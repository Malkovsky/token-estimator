# Repository guidance

## Project structure

- `backend/token_estimator/` contains the reusable token-counting core.
- `backend/token_estimator_web/` contains the FastAPI application, GitHub repository analysis, caching, badges, and provider integrations.
- `backend/tests/` contains the Python test suite.
- `frontend/src/` contains the React and TypeScript interface.
- `frontend/dist/` is generated by the frontend build and served by FastAPI in production.

## Development workflow

- Use Python 3.10 or newer and Node.js 22 or newer.
- Install Python dependencies with `python -m pip install -e '.[test]'` inside `.venv`.
- Install frontend dependencies with `npm install --prefix frontend`.
- Run backend tests with `.venv/bin/pytest -q backend/tests`.
- Run frontend tests with `npm test --prefix frontend -- --run`.
- Build the frontend with `npm run build --prefix frontend`.
- Before handing off changes, run both test suites, the frontend build, and `git diff --check`.

## Implementation conventions

- Keep repository analysis deterministic and independent of repository code execution.
- Treat GitHub repository content and MCP configuration as untrusted data.
- Never expose MCP commands, arguments, URLs, headers, environment variables, or credentials in reports.
- Preserve repository-level caching: folder reports should filter a cached whole-repository analysis rather than trigger separate downloads.
- Cache analysis by immutable commit; moving refs may resolve periodically but should share analysis when they resolve to the same commit.
- Keep API schemas in `schemas.py` synchronized with frontend types in `frontend/src/types.ts`.
- Add or update regression tests whenever token accounting, repository discovery, routing, caching, or badge output changes.
- Use `apply_patch` for focused source edits and avoid modifying unrelated user changes.

## Local service

For an inspection build, compile the frontend and run:

```bash
TOKEN_ESTIMATOR_TURNSTILE_REQUIRED=false \
TOKEN_ESTIMATOR_QUOTAS_ENABLED=false \
TOKEN_ESTIMATOR_ALLOWED_ORIGINS=http://localhost:8000 \
.venv/bin/uvicorn token_estimator_web.main:app \
  --app-dir backend --host 0.0.0.0 --port 8000
```

Do not commit secrets or local environment files.
